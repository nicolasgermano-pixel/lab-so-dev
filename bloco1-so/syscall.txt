# PARTE C — Questões de síntese

# 1. A apresentação afirma que "instruções de I/O são privilegiadas".
#    Como um programa de usuário consegue fazer I/O sem executar
#    instruções privilegiadas diretamente? (mínimo 2 frases)

Resposta 1:
Um programa de usuário consegue realizar I/O fazendo um pedido ao sistema operacional através de uma chamada de sistema (syscall), como a função write(). Em vez de tentar acessar o hardware diretamente (o que geraria um erro de permissão), o programa delega a tarefa ao Kernel. O Kernel, que opera em modo privilegiado (Modo Kernel), assume o controle, executa as instruções físicas de I/O de forma segura e, ao terminar, devolve o resultado e o controle de volta para o programa de usuário.

# 2. Compare write(fd, buffer, tamanho) com o "programa de canal"
#    da apresentação: o que os dois têm em comum em termos de
#    responsabilidades?

Resposta 2:
O elemento dos sistemas modernos que ganha o papel dos antigos é o Controlador de DMA. Assim como os canais do passado, o controlador de DMA é um hardware especializado, e a sua função é realizar a transferência direta de dados entre os dispositivos de I/O (como discos ou placas de rede) e a memória principal. Ele faz isso sozinho, liberando a CPU principal do trabalho pesado para que ela possa continuar processando outras tarefas sem interrupções.
